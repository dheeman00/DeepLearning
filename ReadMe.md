This project focuses on implementing and analyzing supervised learning algorithms across various neural network architectures.

We begin with foundational models such as Perceptrons and Support Vector Machines (SVMs), followed by shallow Feedforward Neural Networks (FNNs). Core training algorithms for these models are introduced and implemented, along with mathematical performance evaluations using principles from data structures and algorithms.

The project then extends to deep learning techniques applied to FNNs with multiple hidden layers. We provide formal analysis on algorithmic correctness and explain why deep architectures outperform shallow counterparts in complex tasks.

Additionally, we explore advanced architectures such as Recurrent Neural Networks (RNNs) and Convolutional Neural Networks (CNNs), focusing on training methodologies and real-world use cases.
